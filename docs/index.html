💻 CLI Command Reference (npm run promptfm)

Airplay, Rotation & Queue Control

Inspect what is currently broadcasting, test rotation clock algorithms, cast votes, and bump tracks to the live airplay queue:

npm run promptfm -- now
npm run promptfm -- next
npm run promptfm -- vote <trackId>
npm run promptfm -- queue next <trackId>
npm run promptfm -- vibe "late night coding synthwave"

Domain & Zero-Egress DNS Audit

Audit DNS zones, migrate Hostinger records, and verify that all streaming traffic is safely routed through Cloudflare to avoid GCP egress bills:

npm run promptfm -- dns status promptfm.live
npm run promptfm -- dns diff stream.promptfm.live
npm run promptfm -- dns validate promptfm.live

SemVer Tagging, Suggestions & Rollback

Generate standardized Git release tags for code, infrastructure, and database migrations, or trigger instant rollbacks:

# Inspect latest tag & suggest next bump
npm run promptfm -- tag suggest [app|infra|sql] --bump patch
# Create & push tag with optional version override
npm run promptfm -- tag infra --version 1.0.0
# Rollback infrastructure or database
npm run promptfm -- tag infra-rollback <targetRef>
npm run promptfm -- tag sql-rollback <version>

📖 Runbooks & Disaster Recovery

Disaster Recovery & Streamer Reboot

If the Icecast or Liquidsoap audio stream experiences connectivity dropouts, execute standard systemd recovery or tunnel restart:

# SSH into Always-Free GCP streamer VM
ssh streamer@stream.promptfm.live
# Restart Icecast 2 & Liquidsoap broadcast containers
sudo systemctl restart docker-compose@promptfm
# Verify stream health
curl -I https://stream.promptfm.live/stream.mp3
Open Station Admin Guide (admin-guide.md) →

Automated Multi-Lane Rollback Runbook

PromptFM supports independent rollbacks for code, infrastructure, and database migrations without redeploying other systems:

# Application Rollback (Vercel)
npm run promptfm -- tag release --version rollback-<sha>
# Infrastructure Rollback (Terraform/Ansible)
npm run promptfm -- tag infra-rollback <targetRef>
# SQL Migration Rollback (Supabase)
npm run promptfm -- tag sql-rollback <version>

⚡ GitHub Actions CI/CD Workflows

Quality Gates & Validation

ci.yml: Runs Vitest unit & integration tests, TypeScript compiler (typecheck), ESLint, Terraform format & state check, Ansible syntax & dry-run, and Stryker mutation verification.
preview-deploy.yml: Zero-cost budget gate protecting Vercel CPU quotas.
retest.yml: Chat-Ops bot listening for /retest comments on PRs.

Deployment & Rollback Pipelines

apply-terraform.yml: Applies Terraform infra upon promptfm-infra/* tags or manual dispatch.
apply-sql-schema.yml: Applies Supabase database migrations upon promptfm-sql/* tags or manual dispatch.
rollback-infra.yml & rollback-sql.yml: Executes safe rollbacks to specific commit SHAs or migration versions.
